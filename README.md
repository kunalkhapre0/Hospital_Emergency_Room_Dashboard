# 🏥 Hospital Emergency Room Dashboard

## 📌 Project Overview

The **Hospital Emergency Room Dashboard** is an interactive data visualization project designed to analyze and monitor emergency room operations. The dashboard provides meaningful insights into patient flow, waiting times, satisfaction levels, admissions, and department referrals. It helps hospital administrators and decision-makers track performance and improve patient care efficiency.

---

## 🎯 Objectives

* Analyze emergency room patient data
* Monitor average waiting time and service efficiency
* Track patient satisfaction levels
* Understand patient demographics and age distribution
* Identify department-wise referral trends
* Support data-driven healthcare decisions

---

## 📊 Key Features

* **Total Patients Count** – Displays the number of patients visited
* **Average Waiting Time** – Measures service efficiency
* **Patient Satisfaction Score** – Evaluates patient experience
* **Admission Status Analysis** – Admitted vs Not Admitted
* **Timely Attendance** – Patients attended within time vs delayed
* **Gender Distribution** – Male and Female patient comparison
* **Age Group Analysis** – Patient count by age range
* **Department Referral Analysis** – Insights into specialist referrals
* **Interactive Filters** – Year and month selection for dynamic analysis

---

## 🛠 Tools & Technologies Used

* Power BI / Data Visualization Tool
* Microsoft Excel / CSV Dataset
* Data Cleaning & Data Modeling
* Charts: Bar, Pie, Donut, KPI Cards

---

## 📂 Dataset

The dataset contains emergency room visit records including:

* Patient demographics
* Waiting time
* Satisfaction score
* Admission status
* Department referrals

*(Data is used for educational and analytical purposes.)*
